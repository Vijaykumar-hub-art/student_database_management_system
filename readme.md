# Student Management System

A beginner-friendly Python and SQL project for managing student records through a command-line interface.

## Features
- Add, view, search, update, and delete students
- Store student records using SQLite
- Calculate grades using SQL CASE statements
- Validate user inputs

## Technologies
- Python
- SQLite
- SQL
- Git and GitHub

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run `python main.py`.
5. Select an option from the menu.

The database and table are created automatically when the program runs.

## Learning Outcomes
Practise Python functions, exception handling, SQL queries, CRUD operations, and database integration.
